O visualizador embutido acima usa three.js. O link "Abrir no gltf-viewer.donmccurdy.com" leva o modelo gerado direto para o visualizador oficial (mais recursos, ex. wireframe e ambientes), buscando o arquivo neste mesmo servidor — funciona quando este servidor estiver acessível pelo navegador (ex. localhost ou uma URL pública).
